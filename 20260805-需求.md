# 🦕 Deno Deploy 边缘原生能力扩展指南

本指南梳理了 Deno 与 Deno Deploy 的核心 API 层级分类，并提供了用于集成到单文件 `main.ts` 中的扩展路由与交互设计建议。

---

## 📊 Deno Deploy 原生能力全景图

按实际开发中的使用频度，将边缘原生能力划分为四大层级：

| 频度层级     | 核心功能 API                   | 实际应用场景                        | 单文件实现方式                            |
| ------------ | ------------------------------ | ----------------------------------- | ----------------------------------------- |
| **高频基础** | `Deno.serve` / Web Standards   | HTTP 路由、JSON 接口、静态网页响应  | 直接返回 `Response` 或 HTML 字符串        |
| **高频基础** | `Web Crypto` (`crypto.subtle`) | HMAC 签名、密钥生成、密码哈希计算   | 调用 `crypto.subtle.digest` / `sign`      |
| **实时流式** | `ReadableStream` / `SSE`       | 大模型 Token 打字机输出、实时日志流 | `new Response(stream, { headers })`       |
| **实时流式** | `Deno.upgradeWebSocket`        | 双向即时通讯、实时聊天室、协作文档  | 升流连接并绑定 `onmessage` 监听           |
| **边缘数据** | `Deno.openKv` / `kv.atomic()`  | 边缘持久化存储、分布式原子计数      | `kv.atomic().sum().commit()`              |
| **边缘数据** | `Deno.cron`                    | 定时任务、定时清理、后台数据轮询    | `Deno.cron("task-name", "* * * * *", fn)` |
| **系统安全** | `Deno.env` & `Permissions`     | 环境变量读取、边缘安全沙箱限制      | `Deno.env.get("KEY")`                     |

## 🛠️ 升级版增量功能与 Endpoint 逻辑

要在已有的 `main.ts` 路由逻辑 (`handleRequest`) 中丰富展示能力，可按需追加以下专有 Endpoint 代码片段：

### 1. 边缘定时任务 (Deno Cron)

无需安装任何第三方 `node-cron` 库，边缘节点原生支持定义定时任务：

```typescript
// -----------------------------------------------------------------------------
// Deno Cron：边缘定时任务 (每分钟更新一次系统运行心跳到 KV)
// -----------------------------------------------------------------------------
if ("cron" in Deno && typeof Deno.cron === "function") {
  Deno.cron("cron-heartbeat", "* * * * *", async () => {
    if (kv) {
      await kv.set(["stats", "last_cron_tick"], new Date().toISOString());
      console.log("[Cron] 心跳刷新成功");
    }
  });
}
```

### 2. 密码学加密与验签 (Web Crypto HMAC)

零依赖生成带秘钥的安全签名（可用于防护恶意机器人、请求防重放）：

```typescript
// -----------------------------------------------------------------------------
// Web Crypto：HMAC 安全签名 API
// -----------------------------------------------------------------------------
if (pathname === "/api/crypto-sign" && req.method === "POST") {
  const { text } = (await readJsonBody(req, MAX_JSON_BYTES)) as {
    text: string;
  };
  const secretKey = Deno.env.get("SECRET_KEY") ?? "deno-default-secret";

  const key = await crypto.subtle.importKey(
    "raw",
    new TextEncoder().encode(secretKey),
    { name: "HMAC", hash: "SHA-256" },
    false,
    ["sign"],
  );

  const signatureBuffer = await crypto.subtle.sign("HMAC", key, new TextEncoder().encode(text));

  const signature = Array.from(new Uint8Array(signatureBuffer))
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("");

  return jsonResponse({
    text,
    algorithm: "HMAC-SHA256",
    signature,
  });
}
```

### 3. KV 分布式定时过期 (KV TTL)

为边缘存储设置生命周期，支持自动超时消除（适用于 Session 管理、临时 Cache）：

```typescript
// -----------------------------------------------------------------------------
// Deno KV：TTL 自动过期缓存 API
// -----------------------------------------------------------------------------
if (pathname === "/api/kv-cache" && req.method === "POST") {
  if (!kv) throw new HttpError(530, "KV 未准备就绪");

  const key = ["cache", crypto.randomUUID()];
  const value = { data: "临时缓存数据", created: Date.now() };

  // expireIn: 60000 表示 60 秒后在 KV 中自动物理消除
  await kv.set(key, value, { expireIn: 60000 });

  return jsonResponse({
    status: "created",
    key,
    ttlSeconds: 60,
  });
}
```
